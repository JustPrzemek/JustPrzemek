# 💫 About Me:
Hello! I'm a backend developer passionate about building robust systems, automation, and security. My primary ecosystem is Java, but I'm not afraid of infrastructure challenges or hardware integration.

* 🔭 **I’m currently working on:** Building robust backend solutions and microservices using Java & Spring Boot, managing databases (mainly PostgreSQL), and configuring complex CI/CD pipelines (Jenkins, Groovy).
* 🎓 **Education:** B.Sc. in Computer Science, currently pursuing my Master's degree in Cybersecurity.
* 🛠️ **Cool stuff I've built:** A Java-based mobile app integrated directly with Zebra RFID scanners. 
* 🌱 **I’m currently learning:** Kotlin (to expand my backend horizons) and Angular (to level up my full-stack capabilities).
* 👯 **I’m looking to collaborate on:** Advanced Java/Spring Boot projects, Kafka messaging systems, deployment automation, and secure backend architectures.
* 💬 **Ask me about:** Java, Spring Ecosystem, Jenkins Multi-branch Pipelines, PostgreSQL, Jakarta EE basics, Cybersecurity concepts, or... my favorite guitar riffs and PC games!
